# The UNIVERSALIS Encyclopedias

**Visibility:** Public UNIVERSALIS repository  
**Repository status:** Initialized with README only; no encyclopedia corpus is present  
**Scope status:** Proposed public destination; pending review and acceptance  
**Version:** 0.0.0 (identity/bootstrap)

## Proposed responsibility

This repository is reserved for public UNIVERSALIS encyclopedia collections and their published editions. It may contain only public-safe, provenance-preserving, rights-cleared material that has passed the applicable source, review, and release gates.

The repository is currently empty apart from this README. No encyclopedia, collection, source list, or research chapter is claimed to be written, verified, reviewed, or published.

## Public source and authority boundary

- No private-source corpus, unpublished source list, private path, credential, or internal operational material belongs here.
- Public-source provenance, license/rights, edition, version, retrieval/creation date, limitations, and unresolved claims must be retained.
- Historical testimony, empirical findings, philosophical positions, tradition-specific teachings, metaphor, modern synthesis, and unresolved claims must remain distinguishable.
- A title or research plan is not a completed encyclopedia.
- A public release classification is not by itself evidence of factual accuracy or independent review.

## Relationship to the UNIVERSALIS ecosystem

The [Public Repository Catalog and Integration Contract](https://github.com/C2O-Chaos-to-Order/The-UNIVERSALIS-Ecosystem/blob/main/ARCHITECTURE/UNIVERSALIS_PUBLIC_REPOSITORY_CATALOG_v0.1.0.md) describes the public repository family. The [UNIVERSALIS Master Ontology](https://github.com/C2O-Chaos-to-Order/The-UNIVERSALIS-Ontology) and public Human/Intelligence domain repositories provide the proposed ontology and domain context. Future encyclopedia entries must cite exact public source artifacts and declared versions.

No automatic synchronization from private research or encyclopedia sources is permitted. Any proposed derivative must first be created as a public-safe artifact with its own provenance and explicit release approval.

## Initial acceptance gate

Before content is added, define collection structure, entry schema, canonical Markdown format, edition/version policy, source register, rights review, editorial review, and crosswalk to the public ontology. Until those contracts exist, this repository remains an initialized destination only.

**Bootstrap note:** This first commit establishes public repository identity and its proposed scope. It does not publish encyclopedia content or certify any claim.
